## Resume local runtime

Start the container if needed: `docker start worktello-feedback-local-mongo`.

From the repository root:

```sh
MONGODB_URI=mongodb://127.0.0.1:27020/worktello_feedback_local COEX_APP_URL=http://localhost:3111 AUTH_URL=http://localhost:3111 COEX_API_URL= COEX_API_MODULES= STORAGE_DIR=/private/tmp/worktello-feedback-storage node node_modules/next/dist/bin/next dev apps/web --port 3111 --hostname 127.0.0.1
```

Seed is idempotent and rejects any other database URI: `MONGODB_URI=mongodb://127.0.0.1:27020/worktello_feedback_local npx tsx scripts/seed-feedback-local.ts`.

Focused DB verification: `MONGODB_TEST_URI=mongodb://127.0.0.1:27020 npx vitest run tests/database/outlook-tasks.test.ts tests/database/contracts.test.ts tests/database/ticket-people.test.ts`.

Test harness now reuses its explicitly isolated Mongoose connection instead of reopening the app URI, and accepts a command-line MONGODB_TEST_URI override. Existing safeguards still refuse clearing non-test databases.
