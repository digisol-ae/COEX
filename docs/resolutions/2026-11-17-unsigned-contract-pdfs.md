# Unsigned contract PDF downloads

Staff can download a saved agreement before internal review or signing. A verified recipient can download the invitation snapshot while signing is pending. Every page carries the DRAFT - UNSIGNED mark.

[PR #92](https://github.com/digisol-ae/COEX/pull/92) reports 467 unit tests, workspace type checks, lint on touched files and visual review of a five-page A4 sample with nested clauses. Production acceptance remains pending.
