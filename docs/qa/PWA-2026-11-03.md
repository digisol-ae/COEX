# PWA implementation checkpoint — 3 November 2026

Source: isolated checkout `worktello-pwa`, branch `codex/worktello-pwa`, based on
main `c236132`. The original mixed checkout and customer-resources branch were
preserved. The managed-worktree API rejected the nested repository path, so this
work uses a separate local clone with its own installed dependencies.

- Installable manifest, branded opaque icons, maskable icon and Apple touch icon.
- App launch uses `/login` so existing role-specific redirects apply.
- Shared account menu links to `/install`; the guide is public and responsive.
- Persistent install-prompt provider with one-use event handling and manual
  installation guidance when the browser does not supply a prompt.
- What's New entry, portable manual instructions and `docs/PWA.md`.
- No database migration, environment change, service worker or offline storage.

Local verification:

- Workspace typecheck passed.
- Focused ESLint passed with zero warnings.
- Application code formatting passed; manual files retain the generator's
  existing JSON/JavaScript formatting, which is outside the CI format glob.
- Unit suite: 69 files / 444 tests passed.
- Webpack production build passed, including `/install` and `/manifest.webmanifest`.
- Production server on local port 3134: guide, manifest and all manifest icons
  returned HTTP 200. Icon dimensions and opaque PNG output were verified, and
  the rendered HTML links the manifest and Apple touch icon.
- Browser guide checked on `http://worktello-pwa.localhost:3134/install` at desktop
  and narrow width. Manual fallback is visible in the in-app browser. Preview:
  `/tmp/worktello-pwa-install.png` (local evidence; not committed).

  17 resolutions. The generated ZIP is outside the checkout.

The first localhost browser attempt inherited an unrelated local session cookie
and tried resolving it against an unconfigured database. An isolated localhost
hostname rendered correctly; no user cookies or data were changed.

the in-app browser, which did not offer a native install prompt. No production
deployment has occurred. Complete the acceptance checklist in `docs/PWA.md`
before rollout.
