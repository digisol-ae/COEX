Do not expose this as a selectable font for third-party content creation or distribute it as a font-library/download service. External contractors must obtain their own copies from Fontshare. This directory contains self-hosted font resources, not CSS or application changes. Declare the mapping above with `font-style: normal` and matching numeric weights.
